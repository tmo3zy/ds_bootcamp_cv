# Определение ориентации кропа с текстом

Для решения задачи был сгенерирован синтетический датасет с симуляцией дефектов с помощью скрипта `data_generate.py`. 

Далее датасет был дополнен реальными размеченными кропами из OCR-бенчмарка Scene Text Recognition. Скачать эти данные можно по ссылке: https://disk.yandex.ru/d/D34tWpLGJWx9Pw

На полученных данных была дообучена легковесная сверточная архитектура `lcnet_100` (`timm`). Выбор модели обоснован высокой скоростью инференса и тем, что модель изначально обучена на текстах и устойчива к локальным геометрическим признакам.

**Оптимизация Brier Score:** 
  * Test-Time Augmentation (TTA): усреднение предсказания исходного изображения и инвертированного предсказания кропа, повернутого на 180°
  * Защитный клиппинг вероятностей в диапазоне `[0.03, 0.97]` для минимизации квадратичного штрафа за чрезмерную уверенность на пограничных и нечитаемых кейсах
  * Разбиение выборки через `GroupKFold` по идентификаторам пар (0° и 180° из одного источника никогда не попадают в train и val одновременно)

## Получение сабмита
Для получения сабмита, аналогичного лучшей попытке, необходимо сначала выполнить `pip install -r requirements.txt`, далее запустить скрипт `data_generate.py`, затем, после скачивания данных по указанной ссылке, запустить скрипт `ext_data.py`. В ноутбуке `train_and_submit.ipynb` для получения сабмита будет достаточно выполнить все ячейки, кроме обучения модели: веса загрузятся с помощью `load_state_dict()` из файла `best_model_3.pth`
